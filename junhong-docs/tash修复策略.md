## 二·补　语义级相互干扰分析 + 防回归机制（核心）

文件级"改不同文件"只是表面。真正要防的是**改 A 的行为变化让 B 或已修好的东西回归**。全系统只有 2 处存在语义耦合：

- **关联① D1 辐射全局**：D1 改变量展开/去引号，是所有命令的必经解析路径（管道/重定向/glob/别名/变量都过它），辐射面最大。
  → 对策：D1 **排最后**；每步全量 902；**做完后复跑前面所有阶段的新测试**，确认无回溯性破坏。
- **关联② D2→D5 行为叠加**：D2 放开触发 → answer 响应变多 → D5 渲染路径更频繁被走。
  → 对策：**先 D5 后 D2**。

其余 D3/D4/D6/D7/R1 之间无语义耦合。

**防回归四机制：**
1. **单调绿灯基线**：D3 先让 902/902 全绿；此后每项修复 = 加该项测试 + 跑全量（902 + 累积新测试），绿灯只增不减。
2. **回退门**：任一项让已有绿灯变红 → 立即回退重做，绝不带回归进下一项（这即防"改D6坏D1"的闸门）。
3. **顺序 = 辐射面小→大 + 被依赖者先改**：`D3 → R1/D7 → D5 → D2 → D4/D6 → D1`。
4. **测试永久累积**：每项测试进套件，后续每项跑全部。
